# Promo Ad Video

Turn a short description of a business, product or offer into a finished 15–30 second animated promo ad with Claude Code.

Claude writes the ad script (hook, problem, product, benefits, price, call to action), picks brand colors and renders an MP4 with kinetic text, sound effects and music. Formats for Reels, TikTok, WhatsApp Status (9:16), feed posts (1:1, 4:5) and YouTube (16:9).

## Use

Ask Claude Code something like *"Make a promo ad for my bakery: sourdough loaves, ₦3,500, order on WhatsApp 0803…"*, or run `/promo-ad-video:promo-ad-video`.

## Requirements

- Node.js 18+ (the video engine installs on first use)
- Optional: ffmpeg

Claude never invents testimonials, customer numbers or fake urgency; prices and contacts are copied exactly.
